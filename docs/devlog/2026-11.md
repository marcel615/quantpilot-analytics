- **재현 조건** — Python 3.12.14와 NumPy 2.3.5에서 `python -m forecast train`, `python -m forecast predict --history-start 2024-11-01 --as-of 2025-01-02`를 실행했다. 정제 일봉과 거래일의 입력 SHA-256은 `05a4efeeca55e4f92991d3a4d644602e58fff76f1c8af0f7b77b032784af2bf2`다. 계정 이용 조건에 따라 실제 가격 파일은 저장하지 않았다.
- **검증 결과** — 학습 334행, 검증 44행, 평가 80행. 검증에서 alpha 0.01을 선택했다. 평가 MAE는 0% 기준선 0.0122974474, 리지 0.0128804021로 차이는 +0.0005829548이다. 동일 입력에서 평가 예측값과 MAE를 재현했고 저장 모델로 2025-01-02 두 종목의 예측을 확인했다.
- **테스트와 리뷰** — `python -m unittest discover -s tests -v` 15개 통과. 자체 리뷰와 독립 리뷰에서 확인한 장 마감 가드와 소수 상수열 표준화를 수정하고 재검증했다. 독립 재검토에서 추가 필수 지적은 없었다.
