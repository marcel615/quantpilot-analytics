# 예측 모델 실험 기록

실험마다 학습 데이터, 예측 목표, 평가 기준, 결과를 같은 순서로 기록한다. 결과를 비교할 때는 평가 종목과 날짜, 표본 수를 함께 확인한다.

## QP-8 — NVDA·SPY 일봉 리지 회귀 (2026-11-24)

- **입력 데이터** — Alpaca Basic IEX의 2024년 NVDA·SPY 미국 일봉 504행. 두 종목을 합쳐 모델 하나를 학습했다. 입력은 최근 1·5·20거래일 수익률, 최근 20거래일 변동성, 직전 20거래일 평균 대비 당일 거래량이다.
- **예측 목표** — 뉴욕 장 마감 기준으로 종목별 다음 거래일의 분할조정 종가 수익률을 예측했다. 배당은 수익률 계산에서 제외했다.
- **평가 기준** — 1~9월 334행으로 학습하고 10월 44행으로 리지 설정(alpha 0.01)을 선택했다. 11~12월의 동일한 평가 80행(NVDA·SPY 각 40행)에서 매일 0%를 예측하는 기준선과 MAE를 비교했다.

| 비교 대상 | 최종 평가 MAE |
| --- | ---: |
| 0% 기준선 | 1.2297%p |
| NVDA·SPY 공동 학습 리지 회귀 | 1.2880%p |

**결과.** 리지 회귀가 평균 0.0583%p 더 빗나갔다. 같은 입력에서 예측과 MAE를 재현했다.

**후속 비교 아이디어.** NVDA 단독 학습과 NVDA·유사 반도체 종목 공동 학습을 같은 NVDA 평가 날짜에 0% 기준선과 비교한다. 최종 평가에는 결과를 아직 보지 않은 기간을 사용한다.

실행 명령과 입력 식별값은 [개발 기록](devlog/2026-11.md)에서 확인할 수 있다. [QP-8](https://marcel615.atlassian.net/browse/QP-8) · [Analytics PR #3](https://github.com/marcel615/quantpilot-analytics/pull/3)

## NVDA 단독 학습 비교 (2026-11-24)

- **입력 데이터** — QP-8과 같은 2024년 Alpaca Basic IEX 표본에서 NVDA 252행을 사용했다. 거래일과 정제 NVDA 행의 SHA-256은 `fd0b191b9c7b502c90b2c1330bc14bbe00a007610cd3e66b3d94939026abbc3d`다.
- **예측과 학습** — QP-8과 동일한 다섯 입력, 다음 거래일 수익률 목표, 리지 후보를 사용했다. NVDA만으로 1~9월 167행을 학습하고 10월 22행으로 설정을 선택했다. 선택된 alpha는 0.01이었다.
- **평가 기준** — QP-8에서 사용한 11~12월 평가 구간을 다시 사용했다. 11월 1일~12월 30일 NVDA 기준 거래일 40건에서 0% 기준선, 기존 NVDA·SPY 공동 학습 모델, NVDA 단독 모델을 평가했다.

| 비교 대상 | NVDA 평가 MAE |
| --- | ---: |
| 0% 기준선 | 1.8606%p |
| NVDA·SPY 공동 학습 리지 회귀 | 1.9310%p |
| NVDA 단독 학습 리지 회귀 | 1.9838%p |

**결과.** 단독 모델의 MAE는 0% 기준선보다 0.1232%p, 공동 모델보다 0.0527%p 높았다. 이번 비교에는 QP-8에서 이미 평가한 날짜를 사용했다. 새 기간에서 평가하면 이 결과가 반복되는지 확인할 수 있다.

**재현.** Python 3.12.14와 NumPy 2.3.5에서 QP-8의 `prepare` 결과를 구간별로 NVDA에 한정해 `select_model`을 다시 실행했다. 공동 모델은 기존 구간 전체에서 학습과 설정 선택을 재현했다. 두 모델과 0% 기준선의 `mae`는 동일한 NVDA 평가 행으로 계산했다.
