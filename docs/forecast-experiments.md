# 예측 모델 실험 기록

실험마다 학습 데이터, 예측 목표, 평가 기준, 결과를 같은 순서로 기록한다. 결과를 비교할 때는 평가 종목과 날짜, 표본 수를 함께 확인한다.

## QP-8 — NVDA·SPY 일봉 리지 회귀 (2026-11-24)

- **입력 데이터** — Alpaca Basic IEX의 2024년 NVDA·SPY 미국 일봉 504행. 두 종목을 합쳐 모델 하나를 학습했다. 입력은 최근 1·5·20거래일 수익률, 최근 20거래일 변동성, 직전 20거래일 평균 대비 당일 거래량이다.
- **예측 목표** — 뉴욕 장 마감 기준으로 종목별 다음 거래일의 분할조정 종가 수익률을 예측했다. 배당은 수익률 계산에서 제외했다.
- **평가 기준** — 1~9월 334행으로 학습하고 10월 44행으로 리지 설정(alpha 0.01)을 선택했다. 11~12월의 동일한 평가 80행(NVDA·SPY 각 40행)에서 매일 0%를 예측하는 기준선과 MAE를 비교했다.

| 비교 대상 | 최종 평가 MAE |
| --- | ---: |
| 0% 기준선 | 1.2297%p |
| NVDA·SPY 공동 학습 리지 회귀 | 1.2880%p |

**결과.** 리지 회귀가 평균 0.0583%p 더 빗나갔다. 같은 입력에서 예측과 MAE를 재현했다.

**후속 비교 아이디어.** NVDA 단독 학습과 NVDA·유사 반도체 종목 공동 학습을 같은 NVDA 평가 날짜에 0% 기준선과 비교한다. 최종 평가에는 결과를 아직 보지 않은 기간을 사용한다.

## NVDA 단독 학습 비교 (2026-11-24)

- **입력 데이터** — QP-8과 같은 2024년 Alpaca Basic IEX 표본에서 NVDA 252행을 사용했다. 거래일과 정제 NVDA 행의 SHA-256은 `fd0b191b9c7b502c90b2c1330bc14bbe00a007610cd3e66b3d94939026abbc3d`다.
- **예측과 학습** — QP-8과 동일한 다섯 입력, 다음 거래일 수익률 목표, 리지 후보를 사용했다. NVDA만으로 1~9월 167행을 학습하고 10월 22행으로 설정을 선택했다. 선택된 alpha는 0.01이었다.
- **평가 기준** — QP-8에서 사용한 11~12월 평가 구간을 다시 사용했다. 11월 1일~12월 30일 NVDA 기준 거래일 40건에서 0% 기준선, 기존 NVDA·SPY 공동 학습 모델, NVDA 단독 모델을 평가했다.

| 비교 대상 | NVDA 평가 MAE |
| --- | ---: |
| 0% 기준선 | 1.8606%p |
| NVDA·SPY 공동 학습 리지 회귀 | 1.9310%p |
| NVDA 단독 학습 리지 회귀 | 1.9838%p |

**결과.** 단독 모델의 MAE는 0% 기준선보다 0.1232%p, 공동 모델보다 0.0527%p 높았다. 이번 비교에는 QP-8에서 이미 평가한 날짜를 사용했다. 새 기간에서 평가하면 이 결과가 반복되는지 확인할 수 있다.

**재현.** Python 3.12.14와 NumPy 2.3.5에서 QP-8의 `prepare` 결과를 구간별로 NVDA에 한정해 `select_model`을 다시 실행했다. 공동 모델은 기존 구간 전체에서 학습과 설정 선택을 재현했다. 두 모델과 0% 기준선의 `mae`는 동일한 NVDA 평가 행으로 계산했다.

## NVDA 예측에 시장과 반도체 업종 수익률 추가 (2026-11-24)

- **입력 데이터** — Alpaca Basic IEX의 NVDA·SPY·SOXX 일봉을 2020-07-27~2023-12-29의 동일한 864거래일에서 검증했다. 총 2,592행이며 입력 SHA-256은 `da1bb975b852e4aab2fb39d6fb926d8dd958c4fc030ee799dbea0eef8aebd34a`다.
- **비교 모델** — NVDA 지표 다섯 가지를 쓰는 기존 리지 모델과, 여기에 SPY와 반도체 ETF SOXX의 당일 분할조정 종가 수익률을 하나씩 추가한 리지 모델을 비교했다. 두 추가 값은 각각 직전 거래일 종가 대비 기준일 종가 변화율이다. 학습 목표는 두 모델 모두 NVDA의 다음 거래일 수익률이다.
- **학습과 검증** — 2020년 7월~2021년 말 342행으로 후보를 적합하고 2022년 250행으로 alpha를 선택했다. 기존 모델은 100, 지표 추가 모델은 0.01을 선택했다. 각 설정을 고정하고 2022년 말까지 593행으로 다시 학습했다.
- **최종 평가** — 앞선 실험의 최종 평가에 사용했던 2024년과 2026년 대신 2023년을 평가했다. 기준 거래일은 2023-01-03~2023-12-28이며 마지막 정답 거래일은 2023-12-29다. 세 방식 모두 동일한 NVDA 249행에서 MAE를 계산했다.

| 비교 대상 | NVDA 평가 MAE |
| --- | ---: |
| 0% 기준선 | 2.1381%p |
| NVDA 지표 다섯 가지 | 2.1379%p |
| NVDA 지표에 SPY·SOXX 수익률 추가 | 2.1912%p |

**결과.** 시장·업종 지표 추가 모델의 MAE는 기존 지표 모델보다 0.0533%p, 0% 기준선보다 0.0531%p 높았다. 기존 지표 모델은 기준선보다 0.0002%p 낮았다. 이 비교에서는 두 지표를 함께 추가했을 때 오차가 커졌다.

**재현.** Python 3.12.14와 NumPy 2.3.5에서 QP-8의 `prepare`, `price_return`, `select_model`을 사용했다. 기준일로 세 종목을 맞춘 뒤 NVDA 행에 당일 SPY·SOXX 수익률을 덧붙였다. 모델 선택과 전처리에는 2022년 말까지의 표본만 전달했다.

## NVDA 시장·업종 지표 비교와 alpha 고정 (2026-11-24)

- **학습 기준** — 직전 실험의 기존 지표 모델이 2022년 검증에서 선택한 alpha 100을 네 모델에 고정했다. 2020년 7월~2022년 말의 동일한 NVDA 593행으로 모델별 전처리와 회귀를 적합했다. 각 비교에서 기존 다섯 지표에 당일 SPY 수익률, 당일 SOXX 수익률 또는 둘 다 추가했다.

- **예측 목표** — 기준일 장 마감에 그로부터 정확히 5번째 거래일의 분할조정 장중 최고가를 예측했다. 목표값은 `5번째 거래일 고가 / 기준일 종가 - 1`이다. 거래일 달력으로 목표 날짜를 정하고 기준일과 목표일이 구간 경계를 넘는 행은 제외했다.
- **학습과 평가** — 2023년 말까지 839행으로 후보를 학습하고, 2024년 247행에서 alpha 100을 선택했다. 2024년 말까지 1,091행으로 모델을 다시 적합했다. 2025-01-02~2025-12-23의 같은 기준 거래일 245건에서 1거래일과 5거래일 오차를 비교했다. 5거래일 예측의 마지막 정답 거래일은 2025-12-31이다.
- **기준선** — 기준일 종가와, 기준일 종가에 해당 예측 기간의 과거 고가 변동률 중앙값을 더한 값을 비교했다. 재학습 데이터에서 구한 중앙값은 1거래일 +1.6382%, 5거래일 +2.9064%다.

| 비교 대상 | 1거래일 변동률 MAE | 1거래일 고가 MAE | 5거래일 변동률 MAE | 5거래일 고가 MAE |
| --- | ---: | ---: | ---: | ---: |
| 기준일 종가 | 2.2375%p | $3.245 | 4.9843%p | $7.127 |
| 과거 변동률 중앙값 적용 | 1.7674%p | $2.554 | 4.6106%p | $6.677 |
| NVDA 리지 회귀 | 1.7566%p | $2.557 | 4.8014%p | $6.973 |

**결과.** 5거래일 리지 회귀의 고가 오차는 같은 기준일의 1거래일 리지 회귀보다 평균 $4.416 컸다. 5거래일에서는 과거 중앙값을 적용한 기준선의 오차가 리지보다 $0.296 작았다.

**재현.** Python 3.12.14와 NumPy 2.3.5에서 QP-8의 `prepare`로 특징을 만들었다. 기준일의 달력 위치에 예측 거래일 수를 더해 해당 거래일의 `high_split`을 목표값에 사용했다. 합성 예제로 중간 거래일에 더 높은 가격이 있어도 5번째 거래일 고가가 목표값이 되며, 구간을 넘는 표본은 제외되는 것을 확인했다.
